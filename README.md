# 🔋 Laptop Battery Status Checker (Python + psutil)

This project is a simple Python script that retrieves your laptop’s **battery percentage and charging status** using the `psutil` library.

---

## ✨ Features
- 🔎 Detects if the laptop is **charging** or **discharging**
- 📊 Displays the current **battery percentage**
- 🖥️ Works on multiple platforms (Windows, Linux, macOS)
